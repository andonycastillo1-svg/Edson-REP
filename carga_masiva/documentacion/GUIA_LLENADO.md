# Guía de llenado

Abra el archivo que le envió IT y lea **INSTRUCCIONES**. Las hojas de captura tienen encabezados fijos, filtros y celdas editables. El asterisco señala qué dato es obligatorio. **EJEMPLOS** contiene muestras ficticias. Escriba los datos reales en la hoja de captura correspondiente.

| Archivo | Quién lo completa | Qué debe entregar |
| --- | --- | --- |
| Colaboradores | Recursos Humanos | Código original, nombre, puesto, región y estado. |
| Usuarios | Administración de usuarios | Correo corporativo, nombre, rol y estado solicitado. |
| Regiones | Administración y operaciones | Nombre exacto y estado vigente de cada región. |
| Relaciones | Administración y responsables de cada operación | Una fila por correo y región, bodega, coordinación, supervisión o acción solicitada. Las hojas separan el perfil de operador, los accesos adicionales y los permisos individuales. |
| Bodegas | Administración y bodega | Nombre exacto, tipo y ubicación. Los responsables se registran en Relaciones. |
| Productos | Compras y responsables del catálogo | Código, nombre, descripción, categoría, unidad y vida útil documentada en meses. |
| Inventario inicial | Bodega | Conteo físico a la fecha acordada por bodega, producto, condición y respaldo. Unidades bajo custodia se registran en el otro archivo. |
| Artículos asignados | Recursos Humanos y bodega | Artículos aún bajo responsabilidad, colaborador, bodega de origen, cantidad y evidencia. La fecha de entrega y vida restante pueden quedar vacías si se desconocen. |
| Compras históricas opcional | Compras y Contabilidad | Una cabecera por proveedor y factura, sus líneas y la confirmación de si el saldo ya refleja esa compra. Úselo cuando IT lo solicite. |

## Cómo completar y entregar

1. Seleccione las opciones de la lista desplegable. Si el archivo base carece de nombres del entorno, pida a IT una copia con los catálogos vigentes. Si una región o producto es nuevo, use la misma escritura en los demás archivos.
2. Copie los códigos como texto, incluidos los ceros iniciales. Una fecha se puede escribir como `2026-11-25` o como fecha de Excel. La vida restante acreditada se registra en días enteros para que se pueda documentar según el respaldo. **Cero** significa agotada y **en blanco** significa desconocida.
3. Use **Nuevo** para proponer un alta, **Actualizar** cuando el cambio esté autorizado y **Verificar** para comprobar un registro sin modificarlo. Si un dato opcional queda vacío en una actualización, se conserva el dato anterior. Para quitar un dato deliberadamente, indíquelo a IT por el canal de aprobación.
4. Use una fila por relación. Por ejemplo, para dar a una supervisora dos regiones, escriba su correo una vez por región. Para dos productos en una factura, repita proveedor y número en **DETALLE HISTÓRICO** y use el código de cada producto.
5. Para el inventario, no sume las unidades entregadas al personal. Use una referencia estable por respaldo o lote. Para las custodias, tome la fecha de entrega del acta original si está disponible y use la fecha de verificación solo para el conteo actual. Si no hay respaldo, acuerde con IT cómo documentar el caso antes de remitirlo.
6. Conserve nombres de hojas y encabezados. Cada hoja admite 1.000 filas. Si necesita más, use otra copia con un sufijo en el nombre del archivo. Pegue valores simples y guarde como `.xlsx`.
7. Envíe los archivos únicamente por el canal interno. En Usuarios y Relaciones se utilizan correos corporativos. Las contraseñas se gestionan por el procedimiento de alta de IT.
