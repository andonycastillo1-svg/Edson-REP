# Edson-REP · Carga inicial y recopilación de información

Kit independiente de la aplicación. Los usuarios completan Excel. IT obtiene un catálogo de solo lectura, revisa el plan y genera SQL para una base de preparación separada. El SQL puede incluir altas y cambios acotados de catálogos cuando IT los aprueba expresamente.

- [Plantillas para usuarios](plantillas_para_usuarios/) contiene los nueve Excel vacíos.
- [Herramientas IT](herramientas_it/) contiene regeneración de plantillas, extracción, validación y conversión.
- [Guía de llenado](documentacion/GUIA_LLENADO.md) para quienes aportan información.
- [Procedimiento IT](documentacion/PROCEDIMIENTO_IT.md) para preparar, revisar, respaldar y verificar.
- [Compatibilidad y reglas de carga](documentacion/COMPATIBILIDAD.md) con evidencias del esquema y decisiones por entidad.

- [Resultados y reproducción de pruebas](documentacion/PRUEBAS.md).

La plantilla histórica de compras se usa cuando Compras y Contabilidad confirman que necesitan centralizar el respaldo. Para cuentas, relaciones, existencias, custodia y compras históricas, el archivo SQL entrega propuestas conciliables en preparación. Los movimientos, el stock, las alertas, los documentos y las credenciales se gestionan por el procedimiento autorizado que corresponda.
